## The Four Process Activities: RetailSync Case Study
During kickoff, the proper documentation was not provided which could have led to differing ideas on the project from team members
During development, the team worked independently with no co-ordination which would have led to issues with each team members work integrating for the final product. The lack of coding standards and code review also may have caused sub-par code to be implemented potentially leading to avoidable bugs and crashed. Warehouse staff were also not consulted which removed valuable insight onto the design of the project from the people who would be using it
During a change of plan, there was once again no proper documentation submitted which would have again led to potentially misunderstood ideas for the project. The overall design was not revisited which should have been done to accommodate the different shelving and barcode system used by the 2nd werehouse
During testing, the team did not do any external/black box testing and only did internal/white box testing which provided them with less valuable information as the testers already knew how the system worked; the internal/whitebox testing also did not include some necessary steps such as test cases. The claim of "basically working" is also not acceptable and should have been "completely working" before being deployed
During Go-Live every problem encounters which lead to a further 3 month delay could have been ignored if the team had simply carried out proper software engineering procedures, such has what has been listed previously

I believe the failure that caused the most damage to the overall project was the the lack of proper testing; the reason for this in my mind is that most of the problems listed previously could have been discovered and fixed if the program was tested properly and more thoroughly. Although you could argue that the lack of code review could have fixed these issues too, I feel like better testing could have led the project to have been deployed with less serious issues and could have stayed in use whilst more issues was fixed and worked on.
